
# 🧮 Calculator

A simple and user-friendly calculator that performs basic mathematical operations. This project is designed to practice programming fundamentals and build a useful application.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔄 Clear and reset functionality
- ⚡ Simple and easy-to-use interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
